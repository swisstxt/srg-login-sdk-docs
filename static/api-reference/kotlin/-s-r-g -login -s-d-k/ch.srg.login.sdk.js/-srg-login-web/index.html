SrgLoginWeb

class SrgLoginWeb(clientId: String, redirectUri: String, environment: String, appId: String, appName: String, appVersion: String, businessUnit: String, businessUnitName: String, postLogoutRedirectUri: String?, enableLogging: Boolean)

JS/TypeScript-facing facade over the SRG Login SDK (@srg/login-sdk).

Method names mirror the Android/iOS public API so developers already familiar with the mobile SDKs recognise them. Kotlin suspend functions are exposed as Promises and the token-state Flow as a subscribe-style callback.

Web uses the top-level redirect model: login navigates the page to the IDP, so it does not resolve with a result; the host completes the flow on its callback route by calling handleRedirect, after which isAuthenticated/getAccessToken/getUserInfo reflect the session.

logout
Link copied to clipboard
fun logout(): Promise<Unit>

Logs out. When a postLogoutRedirectUri was configured, performs a front-channel logout: clears the local session and redirects to the IDP end_session endpoint to terminate the server session (clears the SSO cookie), so the next login prompts for credentials instead of silently re-authenticating. The page navigates away and returns to the post-logout URL. Without a postLogoutRedirectUri, falls back to a local-only logout (tokens cleared, server session untouched).
